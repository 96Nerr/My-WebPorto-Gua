# Nerr | Portfolio

Website portofolio pribadi Naufal Ridho Permana: cyber security, reverse engineering, dan CTF.

Dibangun dengan [Astro](https://astro.build), Tailwind CSS, dan shadcn/ui, berbasis template [astro-erudite](https://github.com/jktrn/astro-erudite).

## Menjalankan lokal

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
